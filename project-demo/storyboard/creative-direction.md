# Automation Context Mapping — 60-second ad

Approved creative input: the owner's six timed voiceover passages and final screen. Output is a local 1920 x 1080, 30fps MP4. Narration follows the supplied copy; `n8n` is pronounced “N eight N”.

Visual language follows the current application: near-black surfaces, warm white type and coral `#ff6d5a`. Open with a fast typographic illustration of scattered work; reveal the real application, then use calm browser footage, readable feature captions, gentle camera moves and a restrained closing logo. Keep closed captions available as an SRT, plus readable burned-in sentence captions. The on-screen logo reuses the application's existing workflow symbol.
