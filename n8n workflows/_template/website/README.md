# Website / App

Optional web app or site that belongs to this automation project (e.g. a form that posts to a
webhook, a client dashboard, a landing page).

When used, document here:

- **Stack:** framework, hosting
- **Run locally:** install / dev / build commands
- **Env vars:** list them in `.env.example` (keys only). Real values are never committed
- **Talks to n8n via:** which webhook paths (and how it authenticates)

Give it its own `AGENTS.md` if agents need stack-specific rules. Delete this folder if unused.
